登入與註冊

  1. OQR 帳號登入，或 Google、Facebook、LINE；iOS 另有 Apple
  2. 註冊分成信箱驗證、手機驗證、填寫資料三段
  3. 註冊進度存在伺服器，中斷後從原步驟接續
  4. 以 Universal Links／App Links 從驗證信直接開到 App

票券列表與本機資料

  1. 進票券頁先比對伺服器，自動下載或取消下載票券
  2. 換手機後，以下載紀錄重新抓回票券
  3. iOS 以 FMDB／SQLCipher 加密本機資料庫，金鑰存 Keychain
  4. Android 以 FCM 即時更新入場狀態

票券資訊

入場 QR Code

  1. 改寫新版入場 QR Code 與聲波判定方式
  2. 兩階段入場：閘門掃描後發出聲波，手機收到才換第二階段 QR Code

  4. 第一次使用先做收音測試，依手機調整判定門檻

已入場

  1. 閘門確認後，票券切換到第二階段 QR Code
  2. 第二階段完成就顯示「已入場」，狀態寫回本機
  3. 已入場的票自動換下一張還沒入場的票
  4. Android 以 FCM 推播，入場狀態即時反映
