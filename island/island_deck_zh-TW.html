角色負責 App（Flutter）、字串管理系統與 CI/CD

開發方式AI agent 實作；本人負責規劃、架構決策、review 與最終驗證

註冊與照片檢查

  1. Google 登入（iOS 另有 Apple 登入），三步驟建立檔案
  2. 中途離開或重新安裝，都會回到上次那一步
  3. 以 flutter_litert 在裝置上檢查照片，不適合的照片在上傳前擋下
  4. 照片上傳前轉成 WebP 並壓縮

字串管理系統

  1. 自建字串管理系統：PM 在後台改文案，不用發新版 App
  2. draft／published 兩個通道：staging 即時看到草稿，production 只讀已發佈版本
  3. 支援 A/B 文案實驗，分組改變時自動同步對應文案
  4. 打包時內建離線底稿，開機後只同步差異
  5. 事件追蹤總表：App 與後端共用同一份事件名稱

CI/CD 與發版

  1. 三種發版方式：本機 Fastlane、GitHub Actions 派工、直接呼叫 CircleCI／Codemagic
  2. GitHub Actions 配號，CircleCI build Android、Codemagic build 並簽署 iOS
  3. iOS、Android、staging、production 共用同一個 build number
  4. PM 驗收 staging 後，以同一個號碼升級為正式版並自動打 tag
  5. 每次 push 自動跑 format → analyze → test

AI 協作流程

  1. AI agent 負責實作；本人負責規劃、架構決策、review 與最終驗證
  2. 以 AGENTS.md 訂定規則與紅線；基礎套件第一次引入由本人決定
  3. implementer／reviewer 分工，跑「規劃 → 實作 → review → 修正」循環
  4. 待辦卡寫明目標、完成條件與驗證方式，新 session 照卡接手
  5. 自訂 skills：一鍵建立測試帳號、發版、同步規格
