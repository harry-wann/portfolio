CI/CD and releases

  1. Three release paths: local Fastlane, GitHub Actions, or CircleCI / Codemagic directly
  2. GitHub Actions assigns the build number; CircleCI builds Android, Codemagic builds and signs iOS
  3. iOS, Android, staging, and production share one build number
  4. After the PM signs off on staging, the same number is rebuilt for production and tagged
  5. Every push runs format → analyze → test
