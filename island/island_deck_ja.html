文言管理システム

  1. 文言管理ツールを内製。PM が管理画面で文言を変更でき、再リリースは不要
  2. draft／published の2チャネル。staging は下書きを即時反映、production は公開版のみ
  3. 文言の A/B テストに対応。グループが変わると対応する文言を自動で同期
  4. ビルド時にオフライン用の文言を同梱し、起動後は差分のみ同期
  5. イベント定義の一覧：アプリとバックエンドで同じイベント名を使用

CI/CD とリリース

  1. 3つのリリース方法：ローカルの Fastlane、GitHub Actions、CircleCI／Codemagic の直接実行
  2. GitHub Actions でビルド番号を採番し、Android は CircleCI、iOS は Codemagic でビルド・署名
  3. iOS・Android・staging・production で同じビルド番号を使用
  4. PM が staging を確認後、同じ番号で本番版をビルドし、タグを自動付与
  5. push ごとに format → analyze → test を自動実行

AI エージェントとの開発フロー

  1. 実装は AI エージェントが主導。要件定義・設計・レビュー・最終検証は自身で担当
  2. AGENTS.md でルールと禁止事項を定義。基盤ライブラリの初回導入は自身で判断
  3. implementer／reviewer の役割分担で「計画 → 実装 → レビュー → 修正」のサイクルを回す
  4. タスクカードに目的・完了条件・検証方法を明記し、新しいセッションでも引き継ぎ可能
  5. 独自の skills：テストアカウント作成、リリース、仕様の同期
