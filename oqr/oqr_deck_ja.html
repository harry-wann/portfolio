プロダクトと担当範囲

2つのアプリで1つのサービス。ユーザーは OQR Ticket でチケットを購入・保存し、QR コードを提示。主催者とスタッフは OQR Manager で入場確認・参加者名簿・集計を行います。

ログインと会員登録

  1. OQR アカウントと Google・Facebook・LINE・Apple でログイン
  2. 5ステップの会員登録：メール・電話番号の認証、基本情報、規約、完了
  3. アカウントは1台の端末に紐付け、機種変更は SMS 認証で移行
  4. OQR Manager も同じアカウントでログインし、ログインと自動更新は共通モジュールに実装

QR コードとチケット画面のタブ

  1. 自社のデジタルキー SDK で QR コードを端末上に生成し、定期的に更新。通信は不要
  2. 2段階で入場：ゲートが読み取ると音波を出し、受信後に2つ目の QR コードへ切り替え。スクリーンショットの不正利用を防止
  3. チケット情報に番号・券種・料金・入場開始時刻・説明を表示
  4. 上部のタブはイベントの設定で表示し、イベント紹介は WebView でサイトを表示

共通モジュールの分割

  1. 共通モジュールを common → user → manager の3領域に分割。OQR Ticket は前の2つ、OQR Manager は3つを利用
  2. 通信・ローカル DB・データモデルを一度だけ実装し、両OSで共通化
  3. Android は library module に分け、iOS も同じ3つでフォルダを分割
  4. ログインが切れたら自動で再ログインして再送。権限チェックと読み取り結果の整形も共通モジュール
  5. 両OSの ViewModel は関数名をそろえ、機能をペアで実装
