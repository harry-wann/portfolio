Shared module by domain

  1. Split into common → user → manager; OQR Ticket uses the first two, OQR Manager all three
  2. Networking, local storage and data models are written once for both platforms
  3. Android uses library modules; iOS mirrors them in folders
  4. Expired sessions sign in again and retry; permission checks and scan results also live in the shared module
  5. ViewModel functions match on both platforms, so features ship in pairs
