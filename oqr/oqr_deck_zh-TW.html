產品與我的角色

一組兩個 App：使用者在 OQR Ticket 購票、把票存在手機、出示動態 QR Code；主辦單位與驗票人員在 OQR Manager 掃描驗票、看參加名單與統計。

2 個 App
使用者端 OQR Ticket、主辦端 OQR Manager
雙平台上架
兩個 App 都有 iOS 與 Android
共用模組
兩個 App 以 Kotlin Multiplatform 共用網路、資料庫與登入
角色從零開發新版 OQR Ticket，再開發 OQR Manager；兩個 App 的 iOS 與 Android 開發與維護
負責範圍iOS、Android 與 Kotlin Multiplatform 共用模組；Android 改以 Kotlin 為主
架構MVVM＋Kotlin Multiplatform；OQR Ticket 另有 Hybrid（WebView）

動態 QR Code 與票券分頁

  1. 以公司自家數位金鑰 SDK 在手機上產生 QR Code，定時更新、不需連網
  2. 兩階段入場：閘門掃描後發出聲波，手機收到才換第二階段 QR Code，防止截圖冒用
  3. 票券資訊列出票號、票種、票價、開放入場時間與票券說明
  4. 上方分頁依活動設定顯示，活動介紹以 WebView 載入活動網頁

選擇活動與掃描驗票

  1. 登入後列出有權限的場次，依權限顯示分頁與按鈕
  2. 使用者在 OQR Ticket 出示 QR Code，驗票人員用 OQR Manager 掃描

  4. 設為入場後，後端推播通知 OQR Ticket 更新畫面，參加名單也同步

共用模組依領域劃分

  1. 共用模組依 common → user → manager 分成三個領域，OQR Ticket 用前兩塊，OQR Manager 用三塊
  2. 網路層、本機資料庫、資料模型只寫一次，iOS 與 Android 共用
  3. Android 拆成 library module，iOS 依同樣三塊分資料夾
  4. 登入失效時自動重新登入再重送請求；權限檢查與掃描結果整理也在共用模組
  5. 兩端 ViewModel 函式名稱一一對應，功能成對完成
